## The fortune

> **A bug you cannot reproduce will reproduce itself in production.**

One line, 63 characters. A fortune cookie for a software engineer: the
bug you could never reproduce on your own machine reproduces itself —
in production, where it counts. The reversal of "reproduce" is the
punchline, and the funniest word, "production", sits at the end.

## How to run

Requires Node 22 or later. No dependencies.

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt` (UTF-8, no trailing
newline).
